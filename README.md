# Local Frequency Mod

A standalone Minecraft Fabric mod exploring local radio presence, temporary pings, and coordinate-based radio towers.

## Current status

Project scaffolding is being established. The first milestone is a configurable radio receiver screen; networking and tower behaviour will be added in later stages.

## Development target

- Minecraft: 1.21.11
- Loader: Fabric
- Project name: Local Frequency Mod

## Planned milestones

1. Radio receiver screen and keybind
2. Tuning sound and audio settings
3. Local player presence
4. Temporary pings and location markers
5. Coordinate-based towers
6. Long-range relay networking

The mod is intended to be usable independently of CivRails. CivRails integration, if added, will be optional.
